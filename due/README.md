# Due（Webアプリ）

**時間になったら、片づけるまで鳴り続ける**リマインダー。iPhone のホーム画面に追加して
片手で使うことを想定した、静的ファイルだけのPWAです。サーバー・DB・ログインはありません。
端末のライト / ダーク設定に追従します。アクセントカラーは赤。

同じリポジトリの[チェックリスト](../README.md)と同じ作りです（1ファイル・localStorage・
Service Worker でオフライン・効果音はその場で合成）。

> iOS の同名アプリの設計思想（しつこく鳴らす・書いたまま入れる・タイマーも同じ場所に置く）を
> まねて自分用に作ったものです。本家とは無関係で、データのやり取りもできません。

## 何が「Due」なのか

ふつうのリマインダーは、時間になったら1回鳴って、気づかなければそれきりです。
Due は**完了にするか「あとで」に送るまで、決まった間隔で鳴り直します**（既定5分おき）。
つまり「見たのに忘れた」が起きにくい。これがこのアプリの中心で、ほかの機能は全部その周りです。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | アプリ本体。HTML/CSS/JS すべてこの1ファイル |
| `sw.js` | Service Worker（オフライン起動のためのキャッシュ） |
| `manifest.webmanifest` | ホーム画面に追加するための情報 |
| `icons/` | アイコン（192/512/maskable） |

`sw.js` と `manifest.webmanifest` はブラウザの仕様上、HTMLに埋め込めないため別ファイルです。

## ローカルで確認する

`file://` で開くと Service Worker が動かないので、簡易サーバーを立てて開きます。

```bash
python3 -m http.server 8000
```
（リポジトリの**いちばん上**のフォルダで実行します）

- PC: <http://localhost:8000/due/>
- スマホ実機: PCと同じWi-Fiにつないで `http://<PCのIPアドレス>:8000/due/`
  （PWA のインストールは `localhost` か HTTPS のみ）

## iPhone で使う

1. Safari で上のURLを開く
2. 共有ボタン（□に↑）→ **「ホーム画面に追加」**
3. 追加したアイコンから起動する（アドレスバーなしの全画面になります）

ホーム画面に追加してから起動すると、次が使えるようになります（iOS 16.4以降）。

- 通知（設定 →「通知を許可する」）
- アイコンの右上のバッジ（時間を過ぎた件数）
- 画面を消さない設定（Wake Lock）

**Safari のタブのままだと通知もバッジも出ません。** 必ずホーム画面に追加してください。

## 使い方（画面）

- **一覧** … 「⏰ 時間です」「今日」「明日」「これから」に分かれて並びます
  - 左の丸を押す → **完了**（トーストの「取り消す」で戻せます）
  - 行の文字を押す → **編集**（用件・日時・繰り返し・削除）
  - 右の「あとで」→ 10分後 / 30分後 / 60分後 / 3時間後 / 明日9:00 / 時間を決める
- **アラーム帯** … 時間になると画面の下に赤い帯が出ます。ここから直接、完了 / +10分 /
  +30分 / 全部まとめてあとで、ができます。「閉じる」で消しても、しつこさの間隔でまた出ます
- **タイマー** … 名前と長さを決めた繰り返し使えるタイマー。0になるとリマインダーと同じように
  鳴り、片づけるまで鳴り直します。「もう一度」で同じ長さをすぐ再開できます
- **ログ** … 完了したものが日付ごとに残ります（60日分）。「戻す」で一覧に戻せます
- **設定** … しつこさ、ワンタップの「あとで」、音、通知、バックアップ、全消去

## 書き方（1行で入れる）

追加のとき、用件と一緒に日時や繰り返しを書くと、そのまま読み取ります。
読み取った結果は入力欄のすぐ下に出るので、違っていれば下の日時欄で直せます。

| 書いたもの | 解釈（金曜10:00に入力した場合） |
| --- | --- |
| `明日 7:30 ゴミ出し` | 明日 07:30 / ゴミ出し |
| `30分後 洗濯物` | 今日 10:30 |
| `あと10分 麦茶` | 今日 10:10 |
| `1時間30分後 出発` | 今日 11:30 |
| `3日後 返却` | 3日後 10:00 |
| `今夜 電話` | 今日 20:00 |
| `明朝 出社` | 明日 07:00 |
| `明後日 会議` | 明後日 09:00 |
| `午後3時 おやつ` | 今日 15:00 |
| `7時半 起床` | 明日 07:30 |
| `水曜 15:00 面談` | 次の水曜 15:00 |
| `9/20 14時 歯医者` | 9/20 14:00 |
| `20日 点検` | 20日 09:00（過ぎていれば来月） |
| `毎日 7:00 薬` | 明日 07:00 から毎日 |
| `毎週月曜 9時 資源ごみ` | 次の月曜 09:00 から毎週 |
| `毎月25日 家賃` | 25日 09:00 から毎月 |
| `3時間ごと 水を飲む` | 13:00 から3時間ごと |

読み取りの決まりごと。

- **時刻だけ**書いて、その時刻が今日はもう過ぎているときは**翌日**にします
  （`3時` は午前3時のこと。午後にしたいときは `15時` か `午後3時` と書きます）
- **日付だけ**書いたときの時刻は **9:00**。それも過ぎていれば、次のきりのいい時刻にします
- 何も読み取れなければ、書いた文字がそのまま用件になり、日時は**1時間後**が入ります
- 日時の直後の「に」「までに」は用件から取り除きます

## しつこさ（自動スヌーズ）

設定で **1 / 5 / 10 / 15 / 30 / 60分おき**から選びます（既定5分）。
時間を過ぎてから、完了にも「あとで」にもしていない項目は、この間隔で鳴り直します。
アラーム帯を「閉じる」で消しても、次の間隔でまた出ます。

## できないこと

サーバーを持たない作りなので、**アプリを閉じている間に鳴らすことはできません**。

- 開いている間は確実に鳴ります（音・端末の通知・振動対応端末なら振動）
- 閉じていた分は、**次に開いたときにまとめて鳴ります**
- iPhone の Safari は `navigator.vibrate` に対応していないため、振動はしません
- 音は端末の**消音スイッチ**の影響を受けます。画面を一度も触っていない状態でも鳴りません

決まった時刻に必ず起こしてほしい用事は、端末の標準アラームと併用してください。

## 仕様メモ

- **保存先**: 端末の localStorage（キー `due.v1`）。他の端末とは共有されません
- **1秒ごと**に、鳴らすものがないか・タイマーの残りを見ています。画面に戻ったときも即座に見ます
- **リマインダーの状態**: `due`（予定時刻）と `snoozeUntil`（あとでに送った時刻）。
  `snoozeUntil` があればそちらが優先。`lastAlert` は最後に鳴らした時刻で、しつこさの起点
- **繰り返し**: `{ n, unit }`（unit は minute/hour/day/week/month/year）。
  完了すると、いまより後になるまで次の回へ進めて一覧に残ります。ログにも1回ぶん記録します
- **タイマー**: `endAt`（鳴る予定の時刻）と `rest`（一時停止中の残り秒）の2つだけで表します。
  絶対時刻で持つので、アプリを閉じていた間もずれません
- **完了ログ**: 60日より前は起動時に自動で消えます（最大2000件）
- **効果音**: 音声ファイルは持たず、Web Audio API でその場で合成する。オフラインでも鳴る
  - 完了 … E6 → B6 のベル（既定）／「ピコン」C6 → G6。設定で選ぶ
  - 追加 … E5 → B5、あとで … A5 → D5、削除・取り消し … G4 の1音
  - アラーム … D6 → G6 を3回。**「音を鳴らす」をオフにしても鳴ります**
    （鳴らないアラームは意味がないため。止めたいときは端末を消音に）
- **配色**: CSS変数で定義し、`prefers-color-scheme` でライト / ダークを差し替える。
  アクセント（時間を過ぎたもの・主要ボタン）は赤、あとでは黄
- **バックアップ**: 設定画面から JSON を書き出し／読み込み。機種変更・データ削除の前に書き出してください

### データ構造（書き出したJSON）

```jsonc
{
  "version": 1,
  "settings": {
    "autoSnooze": 5,          // しつこさ（分）
    "quick": [10, 30, 60],    // ワンタップの「あとで」（分）
    "sound": true, "soundStyle": "bell", "keepAwake": true
  },
  "reminders": [
    { "id": "…", "text": "ゴミ出し",
      "due": 1788500000000,   // 予定時刻(epoch ms)
      "repeat": { "n": 1, "unit": "day" },   // 繰り返さないなら null
      "snoozeUntil": 0,       // 「あとで」に送った先の時刻。0なら送っていない
      "lastAlert": 0,         // 最後に鳴らした時刻（しつこさの起点）
      "createdAt": 1788400000000 }
  ],
  "timers": [
    { "id": "…", "text": "カップ麺", "sec": 180,
      "endAt": 0,             // 動作中なら鳴る予定の時刻
      "rest": 0,              // 一時停止中の残り秒
      "lastAlert": 0 }
  ],
  "log": [
    { "id": "…", "text": "ゴミ出し", "due": 1788500000000,
      "doneAt": 1788500120000, "repeat": true }
  ]
}
```

## アプリを更新したとき

`index.html` などを変更したら、`sw.js` の `const CACHE = 'due-v1'` の数字を上げてください。
上げないと、端末に残った古いキャッシュが表示され続けます。
数字を上げると、次にオンラインで開いたときに「新しいバージョンがあります／更新」と出ます。
