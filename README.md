# チェックリスト（Webアプリ）

コンテキスト（出発前・店を出る前…）ごとのチェックリスト。Android（Chrome）から片手で
使うことを想定した、静的ファイルのみのPWAです。サーバー・DB・ログインはありません。
端末のライト / ダーク設定に追従します。アクセントカラーはフラットなオレンジ。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | アプリ本体。HTML/CSS/JS すべてこの1ファイル |
| `sw.js` | Service Worker（オフライン起動のためのキャッシュ） |
| `manifest.webmanifest` | ホーム画面に追加するための情報 |
| `icons/` | アイコン（192/512/maskable） |

`sw.js` と `manifest.webmanifest` はブラウザの仕様上、HTMLに埋め込めないため別ファイルです。

## ローカルで確認する

`file://` で開くと Service Worker が動かないので、簡易サーバーを立てて開きます。

```bash
python3 -m http.server 8000
```
（このリポジトリを置いたフォルダの中で実行します）

- PC: <http://localhost:8000/>
- スマホ実機: PCと同じWi-Fiにつないで `http://<PCのIPアドレス>:8000/`
  （IPは `ip a` / `ipconfig` で確認。ただし PWA のインストールは `localhost` か HTTPS のみ）

## 使い方（画面）

- **コンテキスト選択** … コンテキストごとに「済んだ件数 / 全件数」と進捗バー（橙＝チェック済み、グレー＝スキップ）
- **チェックリスト**
  - 行のどこを押してもチェック / 解除
  - チェックを入れる / 外す / スキップで、それぞれ別の音が鳴る
  - 時刻を決めた項目には ⏰ のバッジが出る。時刻を過ぎて未処理ならオレンジで強調される
  - 右端の「スキップ」を押すと、その項目は**やらなかった記録**としてグレーになる（「戻す」で解除）
  - スキップもチェックも「済んだ件数」に数える。全部さばけばコンテキストが完了扱いになる
  - 下の「✎ 編集」で、その場で項目の追加・編集・並べ替え・削除ができる
- **設定** … コンテキストの追加 / 削除 / 名前の変更、全項目のまとめ編集、バックアップ、
  音のオン / オフと種類、リマインダー、スリープ設定

## リマインダー

項目ごとに時刻を決めると、その時刻を過ぎてもチェックもスキップもされていない項目を知らせます。
時刻は「✎ 編集」または設定画面の項目編集欄から、項目ごとに設定します。

知らせ方は、画面下の通知帯 ＋ 音 ＋ 振動。端末の通知を許可していれば、通知領域にも出します。
知らせるのは業務日ごとに1項目1回だけです。

**できないこと**: サーバーを持たない作りなので、**アプリを閉じている間の通知は保証できません**。
アプリを開いていれば確実に鳴り、閉じていた場合も次に開いたときに「時間を過ぎている項目」として
知らせます。決まった時刻に必ず鳴らしたい用事は、端末のアラームと併用してください。

## 仕様メモ

- **保存先**: 端末の localStorage（キー `deliveryChecklist.v1`）。他の端末とは共有されません
- **日付の区切り**: 午前4時。深夜〜早朝の作業が前日分として続くようにしています
- **自動リセット**: 日付が変わるとチェックは外れます（アプリを開いたままでも30秒ごとに判定）
- **履歴**: チェック / スキップした時刻を日付ごとに直近60日分だけ保持。それより古いものは自動削除
- **項目の状態**: 「未」「チェック済み」「スキップ」の3つ。スキップにも時刻が残る
- **効果音**: 音声ファイルは持たず、Web Audio API でその場で合成する。オフラインでも鳴る。
  - チェックを入れたとき … 「実績解除ふう」E6 → B6 を、少しずらした倍音を重ねたベル音＋残響（既定）／
    「ピコン」C6 → G6 の素朴な2音。設定で選ぶ
  - チェックを外したとき … A5 → D5 と下がる2音。短く、余韻はほとんど付けない
  - スキップ … B4 の1音だけ。低く短く「トン」と流す
  - リマインダー … C6 → E6 → G6 を2回。いちばん目立つ
  - どれも「音を鳴らす」をオフにすると鳴らない
  - 端末のメディア音量が0のときや、画面に一度も触れていない状態では鳴らないことがある
- **リマインダー**: `item.remind`（"HH:MM"）。業務日ごとに `notified` へ記録して1回だけ知らせる。
  午前4時より前の時刻は、その業務日の「翌日未明」として扱う
- **配色**: CSS変数で定義し、`prefers-color-scheme` でライト / ダークを差し替える。
  アクセント（チェック済み・主要ボタン）はオレンジ、スキップはグレー
- **バックアップ**: 設定画面から JSON を書き出し／読み込み。機種変更・データ削除の前に書き出してください

### データ構造（書き出したJSON）

```jsonc
{
  "version": 4,
  "settings": { "keepAwake": true },
  "scenes": [
    { "id": "…", "name": "出発前",
      "items": [ { "id": "…", "text": "納品書・伝票を持ったか", "remind": "07:30" } ] }
  ],
  "log": {
    // 業務日 → コンテキストID → 項目ID → { at: 時刻(epoch ms), skip: スキップなら true }
    "2026-09-01": {
      "<contextId>": {
        "<itemId>": { "at": 1756770000000 },
        "<itemId2>": { "at": 1756770300000, "skip": true }
      }
    }
  },
  "notified": {
    // 業務日 → 項目ID → リマインドを出した時刻（1日1回だけ出すための記録）
    "2026-09-01": { "<itemId>": 1756770600000 }
  }
}
```

古いバックアップもそのまま読み込めます（読み込み時に version 4 の形へ変換されます）。

- version 1 … 項目IDの値が数値（チェックした時刻）だけ
- version 1・2 … `contexts` ではなく `scenes` という名前だった

## アプリを更新したとき

`index.html` などを変更したら、`sw.js` の `const CACHE = 'checklist-v1'` の数字を上げてください。
上げないと、端末に残った古いキャッシュが表示され続けます。
数字を上げると、次にオンラインで開いたときに「新しいバージョンがあります／更新」と出ます。

設定画面での追加/編集/削除/並べ替え・JSON書き出し/読み込み（不正ファイルの拒否含む）・
リロード後の保持・日付切り替え（午前4時境界／前日分の履歴保持／60日での自動削除）・
コンテキストの追加 / 削除・旧バージョンのデータの自動変換・ライト / ダーク両方の配色・
効果音（チェック / 解除 / スキップそれぞれの音程と倍音の構成・種類の切り替え・設定でのオフ）・
リマインダー（時刻の保存と解除・過ぎた項目の通知帯・1日1回・チェック済みなら出さない・行のバッジ）・
